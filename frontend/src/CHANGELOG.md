## Date Format Details

The date format in File Handle is: `YYYY-MM-DD - HH:MM:SS`

Example: `2025-10-09 - 16:09:02`

This is generated by the `formatDateTime()` function which:
1. Gets current date/time
2. Extracts date in ISO format (YYYY-MM-DD)
3. Extracts time (HH:MM:SS)
4. Combines with " - " separator

## Build Output Structure

When you run `npm run build`, the output will be:

```
dist/
├── index.html
└── static/
    └── assets/
        ├── icon-[hash].png
        ├── index-[hash].js
        ├── index-[hash].css
        └── [other-assets]-[hash].[ext]
```

All asset references in index.html will automatically use the hashed filenames.
